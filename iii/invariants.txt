Representation invariants: 

1. The number of elements in Urray2 is equal to it’s width times it’s height
Example: In a 2D array with width 5 and height 7, there should be 35
        elements in the whole 2D array.

2. The location (row, column) in the array is reachable by indexing 
        (row - 1) * width + (col - 1)
Example: If you are looking for the value of the element in row 2 column 3 in
        Uarray2. Then by indexing to (2-1) * width + (3-1) you should be able
        to reach that element. This is taking into account that we are
        starting out row and collumn counts at 1 and not at 0. If we count
        rows and columns starting at 0 then the equation becomes 
        row * width + col.
